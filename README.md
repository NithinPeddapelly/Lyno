<h1>Lyno</h1>

<h2>Introduction</h2>
<p>Lyno is a seamless and secure video communication platform built for real-time collaboration. Utilizing <strong>WebRTC</strong> and <strong>Socket.IO</strong>, it enables high-quality video and audio calls with minimal latency. Lyno is designed to enhance remote work, online education, and casual conversations with a smooth and private communication experience.</p>

<p>With its optimized WebSockets and scalable architecture, Lyno ensures fast connectivity, superior performance, and strong security. Its lightweight design makes it an ideal choice for quick and hassle-free virtual meetings.</p>

<h2>Features</h2>
<ul>
    <li><strong>Real-Time Communication</strong> – Uses WebSockets for instant data transfer.</li>
    <li><strong>Low Latency</strong> – Optimized for high-quality, smooth video calls.</li>
    <li><strong>Secure & Encrypted</strong> – Ensures privacy with authentication and encryption.</li>
    <li><strong>Scalable</strong> – Supports multiple users concurrently.</li>
    <li><strong>Cross-Platform</strong> – Works on all modern browsers and devices.</li>
    <li><strong>Adaptive Streaming</strong> – Dynamically adjusts video quality based on network conditions.</li>
</ul>

<h2>Technologies Used</h2>
<ul>
    <li><strong>React.js</strong> – Modern JavaScript library for UI development.</li>
    <li><strong>Material UI</strong> – Pre-built UI components for consistent design.</li>
    <li><strong>Axios</strong> – For making HTTP requests.</li>
    <li><strong>React Router</strong> – Enables seamless navigation.</li>
    <li><strong>Socket.io</strong> – Enables real-time communication.</li>
    <li><strong>WebRTC</strong> – Enables real-time video and audio communication.</li>
    <li><strong>Express.js</strong> – Framework for handling API requests.</li>
    <li><strong>MongoDB & Mongoose</strong> – Database and ORM for managing data.</li>
    <li><strong>Bcrypt</strong> – Secure password hashing.</li>
    <li><strong>CORS</strong> – Enables Cross-Origin Resource Sharing.</li>
    <li><strong>CSS</strong> – For custom styling.</li>
</ul>

<h2>Installation</h2>
<p>To run Lyno locally, follow these steps:</p>
<pre>
git clone https://github.com/NithinPeddapelly/Lyno.git
cd Lyno

# Install dependencies
npm install  # or yarn install
npm start    # or yarn start
</pre>

<h2>Usage</h2>
<ul>
    <li>Open Lyno in your browser.</li>
    <li>Register an account or log in.</li>
    <li>Share the unique meeting link with participants.</li>
    <li>Enjoy seamless video calls!</li>
</ul>
